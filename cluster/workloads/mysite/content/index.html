This site is powered by Nginx running on a Raspberry Pi cluster using the k3s Kubernetes distribution.
It's configured with MetalLB, Longhorn, and the Traefik ingress controller.
Deployments are reconciled by Argo CD, with metrics in Prometheus and dashboards in Grafana.
